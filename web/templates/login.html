Prishe

A modular Discord bot for FFXIV-flavored communities — raid sign-ups, birthdays, announcements, and per-server controls, all configured from your browser.

Invite & Configure Explore features →

Setup

Two steps and you're live.

  1. 1

    Invite Prishe

    Add her to your server with one click. She joins lightweight — every module is off-by-default-respecting and toggleable per server, so you only pay the cognitive cost of features you actually use.

  2. 2

    Sign in & customise

    Log in with Discord. The dashboard lists every server you administer. Toggle modules, configure roles, set up the raid calendar, and pick announcement channels — no typed slash commands required.

Slash commands

Type / to discover.

Every Prishe feature shows up in Discord's slash menu. Hit /help at any time for a personal cheat sheet — only you see the reply, with every command, its parameters, and a one-line description. Visibility honours the role allow-lists you set on the dashboard, so members only see what they can use.

Features

Everything Prishe knows how to do.

Modular by design — each feature is a self-contained module loaded at boot. Switch any of them off per-server from the dashboard.

Raid Sign-Ups

FF14-style sign-ups with role buttons, job selection, late/bench/tentative status tracking, and a configurable composition system. Build custom layouts beyond the canonical 2T/2H/2M/1R/1C — any-DPS slots, any-role slots, even job-locked spots like "1 Warrior, 2 healers, 4 any DPS".

Self-Assignable Roles

Curate which roles members can pick up with /role join. Each role can carry a description and a join message; create new Discord roles on the fly or wire up existing ones.

Birthdays

Members save their birthday with /birthday set. Prishe posts a personalised wish on the day, optionally with a random GIF from a per-server library you manage from the dashboard.

Posts & Announcements

Publish rules, news, or info posts as Prishe via a clean composer modal — short title becomes an embed, no title stays plain text. Edit existing posts in place; the modal pre-fills with the current content.

Audit Logging

Server owners can pipe every dashboard change to a channel of their choice. Posts arrive as explicit per-change diffs — exactly which module was toggled, which roles were added or removed, who did it — without spammy generics.

Granular Permissions

Lock each command to specific roles and channels from the dashboard. Visibility in Discord's slash menu syncs automatically — members only see commands they can actually run, and admins always have access.

Dashboard Moderators

Admins can promote any role to dashboard-moderator status. Holders can sign in and manage the same configuration without needing Discord-level admin — owner-only actions (leave server, edit moderator list) stay locked.

Per-Server Everything

Module toggles, command perms, channel allow-lists, raid templates, audit channel, birthday settings — all per-server. Configure one server without touching another. Storage survives restarts on a mounted volume.

A note from the developer

Why this exists.

Prishe is built in Go on top of discordgo. The bot loads each feature as a self-contained module at boot, so adding a new capability never has to touch the existing ones — and disabling any of them is a single dashboard toggle.

The dashboard is the source of truth. Anything you can do via slash commands you can configure visually, and the bot enforces the same role allow-lists at runtime that the dashboard surfaces. No shadow state, no "you have to type it just so."

She's currently in active development. Bear with her :3
